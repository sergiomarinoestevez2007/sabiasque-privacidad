# Política de privacidad – SabíasQué

Última actualización: 16 de noviembre de 2026

SabíasQué es una herramienta privada que usa la API de YouTube Data v3 únicamente para subir y programar vídeos en el canal de YouTube @SabíasQué, propiedad de su autor.

## Datos que se usan

- La herramienta solo accede a la cuenta de YouTube de su propietario, con el permiso de subida de vídeos que él mismo concede.
- El token de acceso se guarda solo en el ordenador del propietario y no se comparte con nadie.
- No se recogen, venden ni ceden datos personales de otras personas.

## Servicios de Google

El uso de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. También se aplican las Condiciones del Servicio de YouTube y la Política de privacidad de Google.

Puedes revocar el acceso en cualquier momento desde https://myaccount.google.com/permissions
